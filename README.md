# ZOROUFE Backend

بک‌اند فروشگاه اینترنتی ظروف لوکس (ظروف و لوازم خانه/آشپزخانه)، با Node.js و Express نوشته شده و دیتابیسش MongoDB Atlas هست (اولش با فایل‌های JSON شروع کردم ولی بعداً کامل مهاجرت کردم به Mongo چون نیاز بود مقیاس‌پذیرتر باشه).

فرانت‌اند هم با HTML/CSS/JS خام (بدون فریم‌ورک) نوشته شده و توی همین ریپو کنار بک‌اند سرو میشه.

## دموی زنده

سایت روی دامنه اختصاصی [zoroufeluxe.ir](https://zoroufeluxe.ir) لایو و در دسترسه.

## استک و سرویس‌های استفاده‌شده

- **Backend:** Node.js + Express
- **Database:** MongoDB Atlas
- **Frontend:** HTML/CSS/JS خام
- **هاستینگ:** Liara
- **آپلود تصاویر:** Cloudinary (برای این‌که تصاویر محصولات دائمی بمونن و با ری‌استارت سرور پاک نشن)
- **پیامک/OTP:** Kavenegar
- **احراز هویت:** JWT + OTP موبایل
- **DNS:** Cloudflare

## امکانات

- پنل ادمین کامل: مدیریت محصولات (چندتصویری، رنگ‌بندی)، سفارش‌ها، تنظیمات سایت، پیام‌های تماس
- فیلتر و جستجوی محصولات (دسته‌بندی، برند، امتیاز، بازه قیمت)، مرتب‌سازی و صفحه‌بندی واقعی از سمت سرور
- ورود با کد یک‌بارمصرف (OTP) از طریق پیامک واقعی
- سبد خرید، لیست علاقه‌مندی‌ها، پیگیری سفارش، تاریخچه سفارش‌های کاربر
- فرم تماس با ثبت پیام در پنل ادمین
- کاملاً ریسپانسیو (موبایل، تبلت، دسکتاپ)
- نماد اعتماد الکترونیکی (اینماد) دریافت شده

## راه‌اندازی لوکال

```bash
npm install
cp .env.example .env
# مقادیر ADMIN_USERNAME / ADMIN_PASSWORD / JWT_SECRET / MONGODB_URI / CLOUDINARY_* / KAVENEGAR_API_KEY رو تو .env عوض کن
npm run dev


## مسیرهای API

### محصولات

| متد | مسیر | توضیح | نیاز به ورود ادمین |
|---|---|---|---|
| GET | `/api/products` | لیست محصولات (با فیلتر) | خیر |
| GET | `/api/products/:id` | جزئیات یک محصول | خیر |
| POST | `/api/products` | ساخت محصول جدید | بله |
| PUT | `/api/products/:id` | ویرایش محصول | بله |
| DELETE | `/api/products/:id` | حذف محصول | بله |

فیلترهای قابل استفاده روی `GET /api/products`: `?cat=kitchen` `?subcategory=...` `?minPrice=` `?maxPrice=` `?sort=cheap|expensive|bestselling` `?search=...`
